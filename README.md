# Permian Basin Production Analysis

Production performance analysis of horizontal wells in the Permian Basin using public data from the Texas Railroad Commission.

## Project Goals
- Acquire and clean well-level production data
- Fit Arps decline curves to estimate EUR
- Benchmark operator performance and well vintages
- Communicate findings in a clear technical writeup

## Status
🚧 In progress — May 2026

## Tech Stack
- Python 3.14
- pandas, numpy, scipy, matplotlib
- Jupyter notebooks for analysis
